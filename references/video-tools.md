# 视频阶段工具调研（后续阶段）

这个文件保留早期视频调研，但视频不再是 skill 的默认工作流。先完成一张通过质量门的 zine 静态图，再把它交给图生视频模型做轻微动效。

## 推荐交接方式

```text
zine still image → image-to-video model → trim to 1–3 seconds → optional Live Photo packaging
```

视频 prompt 只描述已经存在于 zine 静帧中的变化：纸张轻微呼吸、植物或光影变化、人物一个小动作、克制的镜头漂移。不要让视频模型重新读取原始真人照片，也不要要求它重新设计场景。

## 当前选择原则

- **Kling 网页端**：适合先用静帧做 I2V 小样本验证；输入尽量只放已确认的 zine 静帧。
- **Veo / Runway / Luma API**：适合后续批量化和自动轮询，但在静帧流程稳定之前不急于接入。
- **本地动效**：没有 API 时，可以用视差、局部遮罩、纸张纹理和简单循环先做“活的 zine”。

价格、模型名称和网页能力变化较快。真正购买或接入前，应重新核对供应商官方页面；本项目不把这份历史调研当作永久报价承诺。

## API 还是网页端

少量创作优先使用网页端，因为当前主要成本在静态图的风格探索和人工筛选。只有当用户需要批量处理、自动重试、成本记录、统一裁切或 Live Photo 封装时，才值得接入 API。
