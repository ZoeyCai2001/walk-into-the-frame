# Walk Into The Frame：架构理解

## 1. 一句话定义

把摄影师拍过的地方重新编辑成一张 zine：原照片提供场景事实，人物照片提供摄影者的身份线索，图像模型将两者转译成共享同一媒介、纸张、色彩和构图逻辑的静态作品。

核心不是写实抠图，而是**scene distillation + self cameo + visual integration**。

## 2. 当前边界

当前 MVP 只负责生成和评估静态 zine 图像。视频和 Live Photo 暂时不进入默认流程，只有在静态图通过质量门后，才把它交给图生视频模型做轻微动效。

## 3. 创作原则

1. **照片是事实锚点**：保留地点感、主要构图、空间关系、光线和关键细节。
2. **先观察再风格化**：先区分 scene facts 和 treatment choices，不用风格覆盖场景。
3. **人物是叙事标记**：用轮廓、姿态、服装、相机和位置表达“我在场”，不强求写实脸。
4. **同一视觉语法**：人物和场景共享媒介、线条重量、色板、纸张纹理和阴影。
5. **人物不抢主体**：默认小比例、背影/侧影/远景或自然遮挡。
6. **少而准确**：一个主媒介配有限色板和 2–4 个身份线索，避免风格堆叠。
7. **先静后动**：静态关系成立后，再考虑纸张、植物、光影或人物小动作。

## 4. 输入与输出

### 输入

| 输入 | 必需 | 用途 |
| --- | --- | --- |
| `scene_image` | 是 | 风景、街头、建筑、咖啡厅或人文场景的原始照片 |
| `person_image` | 是 | 摄影者本人照片，用于提取轮廓、服装、体态和摄影者线索 |
| `style` | 否 | 手绘明信片、彩铅、纸张拼贴、线稿、Risograph、编辑 zine 等 |
| `mood` | 否 | 安静、旅行手记、怀旧、观察性、轻微幽默等 |
| `participation` | 否 | 走上楼梯、坐在角落、经过街边、站在窗边等 |
| `aspect_ratio` | 否 | 默认保留原图比例 |
| `variants` | 否 | 默认一张；探索时输出 2–3 个方向 |

### 输出

1. 场景提炼摘要：构图、空间层次、核心事实和可用留白。
2. Visual grammar：媒介、色板、纸张/笔触、边缘和细节密度。
3. zine 静态成品图。
4. 人物抽象和放置说明。
5. 质量门结果：场景识别性、风格统一、人物参与感和异常检查。
6. 只有用户明确要求时，才输出后续图生视频 prompt。

## 6. 图像生成策略

优先使用支持多图输入和图像编辑的模型，把场景图标记为主视觉锚点，把人物图标记为身份/参与感参考。GPT Image 2 是这一阶段的合适候选，因为它支持图像输入、图像编辑和高保真图像参考；但它仍应被视为创作工具，而不是像素级排版或精确抠图引擎。

默认尝试一次完成场景 zine 化、人物抽象和融合。若人物位置或风格不稳定，切换为两步法：

```text
原始场景图 → zine scene base → 同媒介人物 cameo → 最终 zine 图
```

两步法的第二步必须引用 zine scene base，避免回到原始照片后重新引入写实人物。

## 7. 质量门

- 至少 3 个场景核心事实仍然可辨；
- 人物和背景属于同一张页面，不像写实贴图；
- 人物的存在感足够表达参与，但不改变主要视觉焦点；
- 人物和场景的线条、色板、纸张、边缘和阴影一致；
- 人物与台阶、椅子、地面、栏杆或植物具有合理接触/遮挡；
- 不出现诡异脸部、额外肢体、重复人物、悬空、穿模、水印或 UI；
- 原照片中的文字不被模型擅自改写成新的可读内容。

## 8. 后续视频路线

视频不是本 skill 的首个交付物。静态 zine 图通过质量门后，可以作为唯一或主要的视频输入，让模型只处理：纸张轻微呼吸、植物或光影变化、人物一个小动作、有限的镜头漂移。不要让视频模型重新从人物原图中认人。

Live Photo 属于输出封装层，不属于 zine 图像生成本身。后续再处理短视频裁切、关键帧配对、元数据和真实设备验证。
