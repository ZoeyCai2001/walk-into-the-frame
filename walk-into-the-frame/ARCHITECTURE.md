# Walk Into The Frame：架构理解

## 1. 一句话定义

把摄影师拍过的地方重新蒸馏成一张稀疏的编辑性 zine 海报：场景照片提供语义、情绪、材质和空间关系，人物照片提供当天的穿搭、轮廓和参与线索，最终图像通过纸面拼贴、印刷、线稿或色块重新成立。

核心不是写实抠图，也不是把照片完整画成插画，而是：

```text
scene distillation + artistic proposition + visual metaphor + photographer cameo
```

## 2. 当前边界

当前 MVP 只负责生成和评估静态 zine 海报。视频和 Live Photo 不进入默认流程，只有静态海报通过质量门后，才把它交给图生视频模型做克制的局部动效。

## 3. 创作原则

1. **照片是语义参考，不是图层**：不保留摄影像素、完整原构图或写实区域。
2. **先蒸馏再创作**：先提取 semantic nucleus、情绪残留、主导手势和 2–4 个 source anchors。
3. **一个命题，一个主要张力，一个视觉隐喻**：所有形式选择都服务于同一作品命题。
4. **比例先于极简**：默认平衡场景拼贴，主体 mass 45–65%、留白 30–45%；只有显式要求极简时才使用 68–85% 留白。
5. **人物是关系型 cameo**：不使用固定画面比例；根据凳子、窗户、台阶、门、栏杆、船、桌子或路径等关系锚点决定尺度，用草帽、服装色块、肩带、轮廓和姿态表达“我在场”。
6. **同一纸面系统**：人物和场景共享媒介、线条、印刷颗粒、色板和边缘。
7. **一个主要色彩事件**：默认 Standard Accent Mode；只有明确触发词才进入 Solid Color-Block Mode。
8. **反装饰化**：不自动加入胶带、邮票、坐标、网格、随机圆点、通用图标或长文字。
9. **拼贴边界不可省略**：默认必须出现主纸窗、辅助纸片、重叠/接缝/断裂和外围留白；主体完整性只能存在于纸窗内部。
10. **米白底纸固定**：原照片的天空、海面、墙面或大面积留白只影响层的形状和节奏，不直接替代整张 zine 的底色。
11. **地点信息有来源**：只有用户提供地点时才加入短小手写 `@Place`，不自行推断地理信息。

## 4. 输入与输出

### 输入

| 输入 | 必需 | 用途 |
| --- | --- | --- |
| `scene_image` | 是 | 语义场景参考；提取地点、关系、材质、情绪和方向 |
| `person_image` | 是 | supporting person reference；提取当天穿搭、帽子、轮廓、体态和摄影者物件 |
| `style` | 否 | cut-paper、dry-print、broken contour、colored-pencil fragment 等 |
| `mood` | 否 | 安静、旅行手记、距离感、观察性、怀旧等 |
| `participation` | 否 | 走向入口、站在门前、被路径带走、观察或停留 |
| `aspect_ratio` | 否 | 默认按源方向使用 5:3 横向或 3:5 纵向 |
| `composition_mode` | 否 | 默认 balanced-scene-collage；显式极简时使用 sparse-distillation |
| `relationship_anchor` | 否 | 凳子、窗户、台阶、门、栏杆、船、桌子、路径等；默认从场景自动选择 |
| `location` | 否 | 用户提供的地点名；默认转成短小手写 `@Place` 标记，不自行推断 |
| `mode` | 否 | 默认 Standard Accent；精确输入 `单色块模式` 才切换 |

### 输出

1. Distillation card 的简短中文摘要。
2. Artistic proposition、central tension 和 visual metaphor。
3. 生成的 raster zine poster。
4. 最终 image-generation prompt。
5. Recipe 与艺术指导：留白、cluster、人物角色、色彩和边缘。
6. 质量门结果和必要的局部重试说明。
7. 只有用户明确要求时，才输出后续图生视频 prompt。

## 6. 图像生成策略

GPT Image 2 或同类图像生成/编辑模型适合承接这一阶段：输入场景图和人物图，按角色标记为 semantic reference 与 supporting person reference，再用 prompt 生成原创纸面构成。

默认不把场景图当作 edit target，因为这会诱导模型保留完整构图。若用户明确要求某个物件或人物必须原样出现，再将对应输入的保留等级提高，并在 prompt 中列出不变量。

推荐的一次生成路径：

```text
scene reference + person reference
→ distillation card
→ new sparse composition
→ abstract cameo integrated into the same paper system
```

如果人物 cameo 不稳定，才使用两步法：

```text
scene reference → zine base → cameo fragment → final poster
```

第二步必须引用 zine base，不能回到原始照片上叠加写实人物。

## 7. 质量门

- 成品是独立的纸面海报，不是满版风景插画或滤镜照片；
- 默认平衡模式下，主体 mass 约占 45–65%，留白约占 30–45%；
- 默认人物与至少一个场景元素形成尺度、接触、遮挡或动作关系；
- 人物比例由关系锚点决定，不用固定占比替代空间判断；
- 默认至少有一张不规则主纸窗和 2–4 个辅助纸片层，能看见边界、重叠、接缝或内部留白；
- 默认底色为米白/暖象牙纸，场景中的天空、海水或墙面只能作为独立层出现；
- 地点标记只来自用户输入，短小、手写、与留白或纸片边缘发生关系；
- 画面有清楚的命题、主要张力和一个视觉隐喻；
- 2–4 个场景锚点仍能说明原始记忆来源；
- 留白、主体 cluster、边界和眼线路径成立；
- 人物的当天穿搭线索可读，但已经转译成同一媒介的 cameo；
- 默认只有一个高饱和色彩重点；
- 不出现原照片像素、写实人脸、贴纸边缘、随机装饰、无关图标、伪造文字、水印或 UI；
- 缩略图下仍然有层级，原尺寸下纸张和印刷材质不过度脏乱。

## 8. 后续视频路线

视频不是本 skill 的首个交付物。zine poster 通过质量门后，可以作为唯一视频输入，让模型只处理纸张呼吸、印刷纹理、植物/光影局部变化或人物一个微小动作。不要让视频模型重新从人物原图中认人。

Live Photo 属于输出封装层，不属于 zine 海报生成本身。后续再处理短视频裁切、关键帧配对、元数据和真实设备验证。
